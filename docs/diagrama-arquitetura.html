→

Azure Container Registry

docker build / az acr build → docker push → ACR

Tutor / veterinário

Acessa o Swagger da API na nuvem e executa o CRUD.

→

ACI · Animed API

Container Java 17, porta 8080, processo com usuário sem root.

→

ACI · Oracle XE

Banco em container, porta 1521. Persiste Tutor e Pet.

As duas instâncias puxam a imagem do ACR. Senha e JDBC vão por variável de ambiente.

RecursoPapel nesta solução
GitHubOrigem do clone no vídeo e dos scripts de deploy.
Azure CLICria o resource group, o ACR e os dois Container Instances. Nada pelo Portal.
ACRRegistro privado das imagens Docker da API e do Oracle.
ACI da APIExecuta o container da aplicação. Expõe Swagger e as rotas REST.
ACI OracleExecuta o container do banco. É aqui que o SELECT do CRUD aparece.
FlywayNa primeira subida aplica o DDL e o seed (script_bd.sql / migrations).
