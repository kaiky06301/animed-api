Animed — arquitetura e esteira CI/CD

Sprint 4 · DevOps Tools & Cloud Computing · Azure DevOps (Repos + Pipelines) → Azure Web App → Oracle FIAP

Fluxo numerado

O que acontece
1O desenvolvedor altera o código na IDE e faz git push na master do Azure Repos.
2O push dispara sozinho a pipeline de CI animed-ci.
3O agente compila com JDK 17 e roda os 13 testes JUnit (H2 em memória).
4O CI publica o artefato animed-api (JAR) e os resultados na aba Tests.
5O artefato novo dispara a pipeline de CD animed-cd.
6O CD lê os dados sensíveis do grupo animed-secrets (senha e JWT como secret).
7O deploy é registrado no environment producao e autentica na Azure pela service connection, sem senha.
8AzureWebApp@1 publica o JAR no Web App e o CD confere o /actuator/health.
9A aplicação conecta no Oracle da FIAP por JDBC e o Flyway aplica as migrations.
10Tutor e veterinário acessam o painel e a API por HTTPS.
